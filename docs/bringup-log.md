# 板级 Bring-up 记录

新板子到手的调试顺序，以及踩过的坑。

## 上电顺序

**分级上电，逐级验证电源轨**，不要一次全焊完再上电。

```
1. 只焊接电源部分（DCDC + LDO），不焊 MCU
   └─ 万用表量 3.3V / 1.8V 空载电压，示波器看纹波 < 50mV

2. 焊 MCU + 晶振，上电
   └─ 量晶振起振（示波器探头 10x，不要碰晶振引脚本体）

3. 烧一个最小固件：只点灯 + 串口打印
   └─ 能打印 = 时钟树配通、Flash 可读写、串口正常

4. 逐个加外设，每加一个回归一次点灯
```

## 外设验证顺序

按"依赖少 → 依赖多"排：

| 顺序 | 外设 | 验证方式 |
|---|---|---|
| 1 | GPIO | 点灯 |
| 2 | USART | 打印 |
| 3 | TIM | 定时翻转 + 示波器量周期 |
| 4 | I2C | 扫地址，读 OLED ID |
| 5 | SPI | 读 LLCC68 版本寄存器 |
| 6 | ADC | 读内部参考电压 |
| 7 | DMA | SPI + DMA 连续收发 |

## 踩坑记录

### 1. SPI 读 LLCC68 全是 0xFF

**现象**：`LLCC68_ReadReg(REG_VERSION)` 返回 0xFF。

**排查**：示波器抓 SCK / MOSI / MISO / NSS 四线。发现 MISO 一直高电平。

**根因**：模块的 NSS 引脚被我接到了 MCU 的 SPI_NSS，但 LLCC68 要求 NSS 由软件控制且在上电后需要一次复位脉冲。

**解法**：改用普通 GPIO 手动控制 NSS，上电后拉低 100µs 再拉高，然后才能正常读寄存器。

### 2. OLED 偶发花屏

**现象**：运行几小时后 OLED 显示乱码，复位后恢复。

**排查**：示波器抓 I2C 波形，发现 SDA 上有毛刺。

**根因**：I2C 上拉电阻用了 10K，总线电容偏大（走了长排线），上升沿变缓。

**解法**：上拉改 4.7K，速率从 400K 降到 200K。花屏消失。

### 3. 电源 IC 虚焊

**现象**：板子上电后 3.3V 只有 2.1V，MCU 反复复位。

**排查**：手摸电源 IC 发烫，万用表量输出脚对地阻值异常。

**根因**：QFN 封装底部散热焊盘虚焊，导致 IC 工作异常。

**解法**：热风枪重新回流，并在 PCB 上把散热焊盘过孔从 4 个增加到 9 个。

### 4. 半孔板焊接

**现象**：模块板与主板连接处间歇性断连。

**根因**：半孔（castellated hole）焊盘吃锡不足。

**解法**：焊前用刀片刮开半孔氧化层，先给孔内补锡，再贴板回流。

### 5. WS2812 级联断点

**现象**：一串 8 颗灯，第 5 颗之后全不亮。

**排查**：示波器逐级量 DIN，发现第 4 颗 DOUT 无输出。

**根因**：第 4 颗灯珠静电损伤。

**解法**：换灯珠。焊接时烙铁接地、戴防静电手环，WS2812 对 ESD 很敏感。

## 工具清单

- 示波器（带协议解码，看 I2C/SPI 波形必备）
- 逻辑分析仪（8 通道够用，抓时序比示波器方便）
- 万用表（量通断、量电压）
- 热风枪 + 电烙铁（0603 / QFN / 半孔都要能焊）
- 放大镜或显微镜（0603 元件肉眼很难检查虚焊）
- 可调电源（带限流，首次上电必用，防止短路烧板）
